## 📌 Overview
**Tinder PRO** is a feature-complete, modern frontend dating web application prototype engineered to combine the core psychological engagement loops of **Tinder**, **Bumble**, and **Hinge**. Built with raw React, pro SVG vector iconography, custom dynamic theme palettes, and rich real-time communication modules, it delivers an immersive user experience.

## ✨ Comprehensive Feature Matrix

| Module | Core Features & Implementation Details |
| :--- | :--- |
| **Authentication & Profile** | Secure onboarding, email/phone state management, custom bio, zodiac badges, relationship intent selectors, and verified blue-tick photo validation. |
| **Discovery & Swiping** | Smooth card stack engine with interactive like/nope triggers, distance calculation, age/gender filters, and dynamic daily swipe limits. |
| **Hybrid Gamification** | • **Blind Date Mode**: Blurs profile imagery until mutual engagement.<br>• **Passport Mode**: Instant coordinate switching for global discovery.<br>• **Stories Tray**: 24-hour video loops with direct story-to-chat dispatch. |
| **Chat & Rich Messaging** | • **Multimedia**: Send images, documents, and interactive Giphy GIFs.<br>• **Voice Notes**: Simulated audio recording with animated live frequency waveforms.<br>• **Reactions**: Quick emoji tapbacks on specific messages.<br>• **AI Assistant**: Instant AI-generated conversation starters. |
| **Video Calling & AR** | Simulated HD peer-to-peer video streaming suite equipped with real-time AR face filters (Virtual Sunglasses & Floating Hearts). |
| **Theming & UI Engine** | Zero-dependency styling featuring dynamic Dark/Light modes and brand-specific accent color switchers (Tinder Rose `#f43f5e`, Bumble Gold `#eab308`, Hinge Violet `#8b5cf6`). |

## 🚀 Getting Started & Installation

### Prerequisites
* **Node.js** (v16+ recommended)
* **npm** or **yarn**

### Quick Setup
Clone the repository and run the following commands in your terminal:

``
# Install dependencies

```bash
npm install
```
# Start the development server
```bash

npm start

```

npm install puppeteer
```bash

npm start & sleep 4 && node take-screenshots.js && killall node

```
